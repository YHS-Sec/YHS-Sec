웹 취약점 분석 · 안전한 백엔드 설계 · 재현 가능한 테스트 · 쓰기 편한 인터페이스

주로 **Python / Flask / JavaScript / Docker**를 사용하고, **pytest / Playwright**로 동작을 확인합니다.
